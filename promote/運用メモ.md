# アイマス楽曲プレゼンシート 運用メモ

公開サイト：https://imasfan-presen.pages.dev/ （release ブランチを push すると約1分で反映）
作業フォルダ：`C:\GitHub\IdolMaster_DB\promote`

サイトは「data フォルダの JSON を読むだけ」の作りです。曲・アイドル・ジャケットを変えるときは、
スクリプトで JSON を作り直して commit → push → release に入れる、という流れになります。

---

## 1. 楽曲の更新の手順

新曲が出た・ふじわらはじめのデータが更新された、などで曲を取り直すときの流れです。

### 1-1. 曲・アイドル・歌唱者・ユニットを取り直す（ふじわらはじめ）

```
python scripts/fetch_data.py sc          # そのブランドだけ（ふだんはこれ）
python scripts/fetch_data.py             # 全ブランド（約50分）
```

- ブランドの名前：`as`（765AS）／`cg`（シンデレラ）／`ml`（ミリオン）／`sidem`／`sc`（シャニマス）／`gm`（学マス）／`876`／`961`
- 1ブランドだけのとき、ユニット（約300件）は前回の結果を使い回します。ユニットも取り直したいときは `--units` を付けます。
  - 例：`python scripts/fetch_data.py sc --units`
  - ユニットだけ取り直す：`python scripts/fetch_data.py units`
- 取った内容は24時間パソコンに保存され、同じ日にもう一度動かしても取りに行きません。必ず最新を取りたいときは `--no-cache` を付けます。
- かかる時間の目安：1ブランド 約10〜25分、全ブランド 約50分（ふじわらはじめに負担をかけないよう、1.5秒ずつ空けて取りに行くため）

### 1-2. ジャケットを付ける

```
python scripts/fetch_jackets.py sc       # 公式ディスコグラフィーから
python scripts/fetch_jackets_itunes.py sc            # Apple Music で探す（確認だけ）
python scripts/fetch_jackets_itunes.py sc --apply    # 見つかったものを書き込む
```

- 公式サイトが先、見つからない曲だけ Apple Music で補います。
- Apple Music の結果は `scripts/.cache/itunes_report.txt` に出るので、取り違えが無いか見てから `--apply` します。
- まだジャケットが無い曲は `scripts/.cache/<ブランド>_unmatched.txt` に出ます。
- 取り直したら、ほかの曲のジャケットが勝手に変わっていないか確認します：`git diff data/jackets.json`

### 1-3. 手で直したいとき（どこを書き換えるか）

| やりたいこと | 書き換える場所 |
|---|---|
| ある曲のジャケットを指定する | `data/jacket_overrides.json`（ブランドごと） |
| 公式ジャケットを2種類から選べるようにする | `scripts/fetch_jackets.py` の `ALT_SERIES`（F＠NTASTIC COMBINATION など）／`COMMON_ALTS`（VOY@GER・なんどでも笑おうの共通盤） |
| 越境曲（ブランドをまたぐ曲）を足す・外す | `scripts/fetch_data.py` の `CROSSOVER_SONGS` |
| 他ブランドの曲をこのブランドにも並べる | `scripts/fetch_data.py` の `EXTRA_SONGS` |
| ふじわらはじめに無い曲を手で足す | `scripts/fetch_data.py` の `MANUAL_SONGS`（例：エクストリーム・オーバードライブ） |
| 歌唱者・ユニットを手で直す | `scripts/fetch_data.py` の `SONG_FIXES` |
| 全体曲にする | `scripts/fetch_data.py` の `WHOLE_SONG_IDS` |
| バージョン違いを別の曲に分ける | `scripts/fetch_data.py` の `SPLIT_VERSIONS` |
| 961プロの曲を足す | `scripts/fetch_data.py` の `MOVED_961` / `SONGS_961` |
| CV を直す | `scripts/fetch_data.py` の `CV_OVERRIDES` |

### 1-4. 確認して公開する

1. 手元で確認：`python -m http.server 8765` で http://localhost:8765/ を開き、曲が検索できるか・ジャケットが出るか・画像が作れるかを見る
2. `assets/app.js` や `assets/style.css` を変えたときは、`index.html` の `?v=` の数字を上げる（変えていなければ不要）
3. commit して push：作業用ブランチ（`feature/add_promote_index`）に commit・push
4. 公開：release ブランチに入れて push（`git push origin HEAD:release`）
5. 1分ほど待って公開サイトを開き、反映されたか確認

※ commit しないもの：`cloudflare_guide.pdf`・`jackets_missing.xlsx`・`jacket_list.xlsx`・`*_jacket_picker.html`

## 2. タグ・イベント（対バンなど）を追加するときの手順

### 2-1. 対バンなどのイベントを追加する

「歌って欲しいアイドル」のブランド選びに、イベント（デレミリ対バン・エムシャニ対バンなど）として出すものです。
ふじわらはじめは使わず、`data/events.json` を手で書きます。

1. `data/events.json` に1件足す（形は既存のものと同じ）

```
{
  "id": "clashmatch",                      ← 英数字の名前（ほかと重ならないもの）
  "name": "デレミリ対バン",                 ← タグ・プルダウンに出る短い名前
  "title": "THE IDOLM@STER ... CLASH M@TCH!!",  ← 正式名
  "source": "https://...",                 ← 出演者の出典（公式ページ）
  "days": [
    {
      "id": "day1",
      "label": "Day1 2/27(土)",             ← 出演日のタグに出る文字
      "members": [
        {"brand": "cg", "name": "渋谷凛"},  ← brand はブランドの名前、name はアイドル名（サイトの表記どおり）
        ...
      ]
    },
    { "id": "day2", ... }
  ]
}
```

2. アイドル名は `data/idols/<ブランド>.json` と同じ表記にする（違うと色やブランドが付きません）
3. 手元で確認：「歌って欲しいアイドル」でイベントを選び、出演日のタグ・「Day1全員」などのボタン・アイドルの一覧が出るか見る
4. 1-4 と同じ手順で commit → push → 公開

- 「まとめて1タグで追加」には、「すべて」のときは「Day1全員」「Day2全員」、出演日を選んだときはブランド別（「Day1シンデレラ全員」など）が出ます。

### 2-2. お題（「まず聴いてほしい曲」など）を足す

- `data/themes.json` に文字を1行足すだけです（並び順のまま候補に出ます）。

### 2-3. 検索用のタグ（ユニット名・グループ名）を足す

| やりたいこと | 書き換える場所 |
|---|---|
| 越境曲に「スタマス」のような検索用の名前を付ける | `scripts/fetch_data.py` の `CROSSOVER_TAGS` |
| グループ全員が歌う曲にグループ名を付ける（例：Dearly Stars・vα-liv） | `scripts/fetch_data.py` の `GROUP_TAGS` と `GROUP_TAG_KANA`（よみ） |
| ユニット名を公式表記にそろえる（例：noctchill） | `scripts/fetch_data.py` の `UNIT_OFFICIAL` |
| 「歌：」に出さない検索用の名前 | `assets/app.js` の `NOT_UNIT` |

- 書き換えたら、そのブランドを取り直す（例：`python scripts/fetch_data.py sc`）と、曲のデータに反映されます。

### 2-4. 「歌って欲しいアイドル」のユニット・グループ分け

| ブランド | 分け方 |
|---|---|
| シャニマス・SideM | ユニットごと（ユニット名・色・並びは imas-db.jp のカラーコード一覧から自動。公式表記は `UNIT_OFFICIAL`） |
| 876プロ・961プロ | `scripts/fetch_data.py` の `BRANDS` の `pick` に書いた `group`（空にするとグループ無し） |
| ミリオン | MILLION STARS／その他（参加曲数で自動） |

### 2-5. ブランドを足す

1. `data/brands.json` に1件足す（id・名前・短い名前・色）
2. `scripts/fetch_data.py` の `BRANDS` に取り方を書く
3. `scripts/fetch_jackets.py` の `SOURCES` にジャケットの取得元を書く
4. 1-1 → 1-2 → 1-4 の順に進める
